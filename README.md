 # Titan Hard 🖥️

### Final e-commerce project focused on hardware and technology products, developed with HTML, CSS, JavaScript, and Bootstrap.

### 🚀 Features
- Product catalog
- Shopping cart system
- Cart details modal
- Responsive design
- Interactive navbar
- Product categories
- Gamer/tech-inspired UI
- Promotional banners and sliders
- Login and register pages
- Custom 404 error page
